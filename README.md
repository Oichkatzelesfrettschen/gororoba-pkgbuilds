# gororoba-pkgbuilds

Arch Linux and CachyOS recipes for the libraries, SDKs and tools the gororoba
research workspace builds on: quantum computing stacks (Qiskit, Amazon Braket,
vendor SDKs), hypercomplex and geometric algebra libraries, numerical and
linear-algebra packages, and supporting command-line tools. Each recipe tracks
an upstream release through nvchecker, and CI builds and tests every change in
a clean Arch container.

Layout and rules: [AGENTS.md](AGENTS.md). Pipeline: [docs/package-update-ci.md](docs/package-update-ci.md).
Origin of each recipe: [PROVENANCE.tsv](PROVENANCE.tsv).
